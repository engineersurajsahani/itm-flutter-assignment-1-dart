# Dart Assignment — Correct First 10 Questions

These files correspond to the first 10 questions shown in the provided screenshot.

1. Declare all primitive types in Dart
2. Swap two numbers
3. Largest of three numbers (ternary)
4. Even or odd using bitwise
5. Arithmetic operations
6. Increment / Decrement
7. String comparison
8. Celsius to Fahrenheit
9. Area of shapes using constants

Each `.dart` file is standalone and can be run with:

