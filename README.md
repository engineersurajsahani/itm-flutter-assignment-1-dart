# ITM Flutter Assignment 1 — Dart Solutions

This repository contains runnable solutions for all **100 practice questions**. Each question is implemented in its own standalone Dart file under `Paramvinayak-133/`, named `question_001.dart` through `question_100.dart`. Shared classes and helper declarations are kept in `Paramvinayak-133/common.dart`.

## Run one question

Install Dart 3 or newer, then run any question independently:

```bash
dart format Paramvinayak-133
dart analyze Paramvinayak-133
dart run Paramvinayak-133/question_001.dart
```

Change the filename to run any of the 100 questions. Every question file has its own `main()` and imports the shared support declarations.

The original assignment is available at [engineersurajsahani/itm-flutter-assignment-1-dart](https://github.com/engineersurajsahani/itm-flutter-assignment-1-dart).
